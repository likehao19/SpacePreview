01 / 为快速查看而设计

少一步打开，多一点专注。

围绕“看一眼”这件小事，把常用能力放在顺手的位置。

⌨

空格，直接预览

Windows 资源管理器、桌面与 macOS Finder 中选中文件，按下空格查看，再按一次返回。

↗

让查看快一步

速度与资源占用优先。PDF 按可见页绘制，ZIP 按需读取，切换或关闭时取消旧的解析任务。

▤

压缩包里，继续看

浏览 ZIP、TAR、7Z 等归档的目录层级，打开其中支持的图片、文本与文档，无需先完整解压。

Aa

阅读，清晰有序

Word / Markdown 大纲、文本搜索、字体字号和缩放。代码高亮，结构化代码支持按条件折叠。

⌂

本地文件，本地处理

只读预览，不修改原文件，不上传内容。文档脚本与 Office 宏不会执行，Notebook 单元格不会运行。

⚙

按你的习惯使用

明暗主题、自定义预览键、可选开机自启动和应用内更新，工具集中在「更多」菜单中。

接入引擎不等于所有文件变体均已验证。 表格保留已接入的类别，具体范围如下：

  • 相机 RAW：本次验证 CR2、KDC 样本，其余列出的相机格式已接入但尚未逐一验收；通用 .raw 文件不支持。
  • 设计文件：KRA、Sketch、XD、XMind、FIG、CDR、PIX/PIP、PDN 仅尝试读取内置预览图，已用结构样本验证；非 ZIP FIG、旧版 CDR/PDN 等变体不保证可用，不还原完整设计画布。
  • Office：旧 DOC 仅文字速览；PPT 静态页面依赖 Windows 本地安装并激活 PowerPoint。复杂 Word 排版与 OpenDocument 原始布局可能不同。
  • 三维 / CAD：本次验证 BLEND 样本为 Blender 2.48，不保证所有新版；GLTF 需内嵌几何，不加载外部贴图与动画。LWO 已接入但尚未验收，暂不列入上表。
  • 容器与数据库：MSI 等仅浏览文件 / 流，不等于安装包语义解析；PAK 仅限 Chromium 变体；DB 等仅识别 SQLite 内容，GPKG / MBTiles 不显示地图。
  • 图片、字体与媒体：依赖系统和解码器的支持范围；WMF/EMF 为 GDI 子集，WOFF2 的完整字形解析有限。音视频不保证所有内部编码均可播放。

本轮验收环境为 Windows Edge，其他系统未在本轮实机验收；不同格式还有独立的大小、页数等限制。查看本次核对记录 ↗

FAQ

开始之前。

三个系统都支持空格唤起吗？

Windows 支持资源管理器和桌面；macOS 已接入 Finder，需要辅助功能与自动化授权，相关兼容性仍需真机验收。Linux 当前通过拖入文件或 Ctrl+O 预览，尚未接入文件管理器空格唤起。

Office 文档能完全还原吗？

Word 支持页面、图片、表格和大纲，复杂排版、公式及缺失字体可能影响显示。PowerPoint 静态页面需要 Windows 本地安装并激活 Microsoft PowerPoint；其他情况提供文字速览。

大文件预览有什么限制？

默认单文件大小上限为 512 MiB，可在偏好设置中调整为 16–2048 MiB；压缩包内单文件默认 256 MiB，最高可设为 1024 MiB，各格式仍有独立解析限制。部分格式完整读取后再展示，实际速度与内存占用取决于文件及设备；尚未完成 GB 级真实文件的性能验证。
